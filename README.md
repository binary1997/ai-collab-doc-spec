# AI 协作开发文档规范（五文件版）

> 面向「人 + AI 协作开发」的**中文**文档结构规范。
> 一句话：**用五个文件，把「多模型接力开发」变成一条有合同、有验收、可追溯的流水线。**

## 它解决什么

当开发被拆成多个 AI 会话接力时，三个问题必须先有答案：

1. **每棒手里该拿什么？** —— 规划棒产出任务书，实现棒只拿任务书，验收棒拿冻结版任务书
2. **怎么保证实现与规格不脱节？** —— 任务书是**唯一合同**，版本冻结，验收只认它
3. **人怎么快速核对 AI 干了什么？** —— 验收报告必须三档：✅通过附证据 / ❌不通过指位置 / ⚠️规格没写清

## 五文件

| 文件 | 职责 | 更新语义 |
| :--- | :--- | :--- |
| `AGENTS.md` | 常驻层：规范 + 结构 + 约束 | 契约变才改 |
| `项目任务书.md` | 当前阶段的详细执行规格 | **覆盖** |
| `项目决策记录.md` | 每个决策「为什么」，含翻转原因 | **只追加** |
| `代码踩坑记录.md` | 踩过的坑 + 排查过程 + 修法 | **只追加** |
| `CHANGELOG.md` | 每次改了什么 | **只追加**（AI 永不读） |

## 配套流水线

| 顺序 | 谁 | 读什么 | 产出 |
| :-: | :-: | :--- | :--- |
| ① 规划 | 高价模型 | 五文件 + 项目现状 | 《项目任务书》 |
| ② 实现 | 低价模型 | **只拿任务书** | 代码 |
| ③ 验收 | 高价模型 | **冻结版任务书** + 代码 | 三档验收报告 |
| ④ 终验 | **人** | 真机 / 模拟器 | 通过 / 打回 |

## 怎么用

把 [`文档结构规范.md`](./文档结构规范.md) 贴给 AI 即可 —— 它自带 §〇 启动指令，
AI 会勘察你的项目、生成专属五文件、跑完自检、然后**删掉自己**。

> 📌 本文件是**一次性模板**，不是项目资产。
